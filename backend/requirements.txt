# IMPORTANT - Python version compatibility
# ----------------------------------------
# The pins below are chosen so that every package installs from a PREBUILT WHEEL on both
# Python 3.12 and Python 3.14 (verified with tools/resolve_pins.py). No Rust or C
# compiler is required.
#
# `pydantic-core` is the package that catches people out: it is a compiled extension and
# older releases (for example 2.27.x, which pairs with pydantic 2.10) only support up to
# Python 3.13. On Python 3.14 pip then falls back to building it from source and fails
# with:
#     error: the configured Python interpreter version (3.14) is newer than
#            PyO3's maximum supported version (3.13)
# pydantic 2.14.1 -> pydantic-core 2.50.1 ships cp312 *and* cp314 wheels, so it works on
# both. Check availability for any interpreter with:
#     python tools/resolve_pins.py --tag cp312 --tag cp314
